# 术语对照（可在翻译时先行扩充）

首次出现写「中文（English）」（如「持续合成能力（processivity）」），此后用中文；**不得只写英文**。基因/蛋白/载体/引物/buffer/试剂货号保留原文。

说明列写**原文照写**的条目是例外：这类词译成中文反而不准，正文一律照原文写、不加括注（如 5′UTR、poly(A)）；中文列与英文列相同的条目同样按原文处理。校验时这类词只要原文写法或译名出现任一即可，不判术语漂移。

## 排版约定

- 章节：Materials and methods → 材料与方法；Introduction → 引言；Results → 结果；Discussion → 讨论。
- 图表：Fig. N → 图 N；Table N → 表 N；Extended Data Fig. N → 扩展数据图 N；Supplementary Fig. N → 补充图 N。
- 数字与单位之间、中文与拉丁字母之间加一个半角空格。
- 引用上标：正文中 `...已有报道~{12,13}`，构建时转 Word 真上标。
